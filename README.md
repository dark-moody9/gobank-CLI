# 💰 Go Bank CLI App

A simple command-line banking system built with Go.

## 🚀 Features
- Check balance
- Deposit money
- Withdraw money
- Persistent storage using file system

## 🛠 Tech Used
- Go (Golang)
- File handling
- Error handling

## ▶️ How to Run
1. Clone the repo
2. Run:
   go run bank.go
